How it works

  1. User enters four flower measurements.
  2. Frontend sends the data to the Flask API.
  3. Flask validates the input.
  4. The trained ML model processes the input.
  5. The model predicts the flower species.
  6. The API returns the prediction and confidence.
  7. The frontend displays the result.

Containerization with Docker

Dockerfilerequirements.txtApplication

The application and its dependencies are packaged into a Docker container so that it can run consistently across development and cloud environments.

docker build -t iris-ml-app .
docker run -d --name iris-ml-app -p 5000:5000 iris-ml-app

About the Project

Problem statement

Machine learning models are often developed locally but need to be exposed through reliable APIs and deployed in cloud environments for real-world use.

Solution

Our system trains an Iris classification model, exposes it through a Flask REST API, packages the application using Docker, and deploys the container on AWS EC2.

Objectives

  1. Build a working Machine Learning classification model.
  2. Create a REST API for ML predictions.
  3. Create a user-friendly web interface.
  4. Containerize the application using Docker.
  5. Deploy the container on AWS EC2.
  6. Demonstrate cloud-based ML model serving.
  7. Provide API health monitoring.
  8. Demonstrate scalable deployment concepts.

Advantages

  • Easy access through web browser.
  • Portable Docker deployment.
  • Separation between frontend and ML API.
  • Cloud accessibility.
  • Easy model integration.
  • Reproducible environment.
  • Simple API integration.
  • Easy future scaling.

Future scope

  • Deploy larger ML models.
  • Add authentication.
  • Add a database for prediction history.
  • Add AWS Load Balancer.
  • Add HTTPS.
  • Add CI/CD using GitHub Actions.
  • Deploy multiple containers.
  • Add model monitoring.
  • Add automatic model retraining.
  • Move serving to AWS SageMaker for production scale.
