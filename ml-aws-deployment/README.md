# Cloud ML Predictor – Iris Classification on Docker & AWS EC2

A complete machine-learning deployment project: a scikit-learn model served through a Flask REST API, wrapped in a responsive web interface, packaged with Docker and deployable on a single AWS EC2 instance.

## Features
- Real Logistic Regression model trained once and loaded from `model.pkl` at startup
- REST API (`/predict`, `/health`, `/api/info`) with input validation and JSON errors
- Responsive single-page UI: Home, Prediction, Model Info, Architecture, API docs, About
- Deployment status card driven by real `/health` and `/api/info` responses
- Model accuracy measured during training and reported by the API (nothing hardcoded)
- Dockerfile with gunicorn and a health check; optional GitHub Actions CI; pytest tests

## Technology stack
Python 3.11 · Flask · Flask-CORS · scikit-learn · joblib · NumPy · gunicorn · HTML/CSS/JavaScript · Docker · AWS EC2

## Machine learning model
Iris dataset (from scikit-learn, no download). Features: sepal length/width, petal length/width. Classes: Iris Setosa, Versicolor, Virginica. 80/20 stratified train/test split, Logistic Regression, accuracy computed on the test split and stored in `model.pkl`.

## Architecture
```
User → Web interface (HTML/CSS/JS) → Flask REST API → scikit-learn model → Docker container → AWS EC2 → Public internet
```

## Run locally
```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements-dev.txt
python train_model.py             # train the model -> model.pkl
python app.py                     # run Flask
```
Open http://localhost:5000. Run the tests with `pytest -q`.

## Docker
```bash
docker build -t iris-ml-app .
docker run -p 5000:5000 iris-ml-app
```
The container serves the app with gunicorn on `0.0.0.0:5000` and re-trains the model during the build so `model.pkl` always matches the installed scikit-learn version.

## Deploy on AWS EC2
1. **Create an instance**: EC2 → Launch instance → Amazon Linux 2023, `t2.micro`/`t3.micro`, create or choose a key pair.
2. **Security group** inbound rules: SSH TCP 22 (restrict to *My IP*) and Custom TCP 5000 (0.0.0.0/0 for the demo).
3. **Connect**: `ssh -i your-key.pem ec2-user@EC2_PUBLIC_IP`
4. **Install Docker and Git**
   ```bash
   sudo dnf update -y
   sudo dnf install -y docker git
   sudo systemctl enable --now docker
   sudo usermod -aG docker ec2-user
   exit        # then SSH in again so the group change applies
   ```
5. **Clone and build**
   ```bash
   git clone YOUR_REPOSITORY
   cd ml-aws-deployment
   docker build -t iris-ml-app .
   ```
6. **Run**: `docker run -d --name iris-ml-app --restart unless-stopped -p 5000:5000 iris-ml-app`
7. **Verify**: `docker ps` and `curl http://localhost:5000/health`
8. **Open** `http://EC2_PUBLIC_IP:5000` in a browser.

Notes: the "Cloud: AWS EC2" status turns green when the app can reach the EC2 metadata service. If it shows "EC2 not detected" from inside Docker, raise the hop limit: `aws ec2 modify-instance-metadata-options --instance-id <id> --http-put-response-hop-limit 2 --http-tokens required`. To stop paying for the instance, terminate it after the demo.

## API documentation
| Method | Path | Purpose |
|---|---|---|
| GET | `/` | Web application |
| POST | `/predict` | Predict species |
| GET | `/health` | Health check (503 if the model is not loaded) |
| GET | `/api/info` | Project and model info including accuracy |

Example request:
```bash
curl -X POST http://localhost:5000/predict -H "Content-Type: application/json" \
  -d '{"sepal_length":5.1,"sepal_width":3.5,"petal_length":1.4,"petal_width":0.2}'
```
Example response (confidence is the model's real probability, so exact digits vary):
```json
{"success": true, "prediction": "Iris Setosa", "confidence": 0.9772,
 "probabilities": {"Iris Setosa": 0.9772, "Iris Versicolor": 0.0228, "Iris Virginica": 0.0}}
```
Invalid input returns HTTP 400: `{"success": false, "error": "Please enter valid numerical values for all four features."}`. Each value must be a number greater than 0 and at most 20.
